# 전시물 정본 — 표 · 그래프 · 도표

`theme.md` 가 색의 정본, `tone.md` 가 문장의 정본이듯 이 파일이 **그림의 정본**이다.
자매 스킬 `kernel-html-reports` 도 같은 규칙을 쓴다.

완성형은 `reference/전시물_갤러리.html`(21장). 막히면 그것을 편다.
숫자에서 조각을 뽑는 도구는 `scripts/mkchart.py`.

> **어디까지 실측했나.** 표·그래프 CSS 와 `mkchart.py` 출력은 **1280×720 슬라이드 캔버스에서만**
> `slidecheck.ps1` 로 쟀다(갤러리 21장 판정 통과). **A4 지면에서는 아직 안 재봤다** — 보고서에
> 그래프를 넣으려면 `printcheck.ps1` 로 먼저 재고 이 문단을 고친다. 표와 도표 규칙(§3·§5)은
> 형태와 무관하므로 양쪽에 그대로 적용된다.

## 0. 순서를 뒤집지 않는다

**데이터가 형태를 정하지 않는다. 메시지가 정한다.**

1. **메시지를 한 문장으로 쓴다.** 숫자가 들어가야 한다. "지연 사유 422건 중 184건이 카드 증빙이다"
2. **그 문장에서 비교 유형을 읽는다.** 낱말이 이미 형태를 가리킨다(§1)
3. **형태를 고른다.** 유형이 형태를 정한다
4. **강조를 하나만 남긴다.** 나머지는 회색으로 눕힌다
5. **잰다.** `slidecheck.ps1`

이 순서를 뒤집으면 가진 데이터를 다 그리게 되고, 그 순간 한 장에 뜻이 둘 이상 들어간다.

**제목이 곧 결론이다.** 그림을 손으로 가리고 제목만 읽었을 때 할 말이 남아야 한다.
"월별 마감 소요일"은 제목이 아니라 이름표다. "마감이 13일에서 5일이 됐습니다"가 제목이다.

## 1. 비교 유형 다섯 (Zelazny)

메시지 안의 낱말을 본다. 다섯 중 하나에 걸린다.

| 유형 | 신호가 되는 말 | 형태 | 조건 |
|---|---|---|---|
| **구성비** | 비중 · 몫 · 퍼센트 · 차지한다 | `sbar` 100% 누적 가로 막대 | 항목이 다섯을 넘으면 나머지로 묶는다 |
| **항목** | 가장 큰 · 상위 · ~보다 · 대비 | `bars` 가로 막대 | 큰 것부터 내려 정렬. 시간순으로 두지 않는다 |
| **시계열** | 늘었다 · 줄었다 · 추세 · 이후 | `cols` 세로 막대 / `line` 꺾은선 | 시점이 여섯 이하면 막대, 넘으면 꺾은선 |
| **빈도** | 분포 · 구간별 · 몇 건씩 | `cols` 세로 막대 | 구간 폭을 같게 자른다 |
| **상관** | 따라 움직인다 · 관계 · 클수록 | `dot` 점 | 점이 스무 개 미만이면 표가 낫다 |

여기에 실무용 하나를 더 둔다.

| **다리** | A에서 B로 왜 갔나 · 어디서 줄었나 | `wf` 워터폴 | 항목이 일곱을 넘으면 묶어서 줄인다 |

## 2. 매번 사고를 내는 넷

| 하지 않는다 | 왜 | 대신 |
|---|---|---|
| **파이 차트** | 사람은 각도를 못 읽는다. 두 조각이 비슷하면 순위조차 안 보인다 | 100% 누적 가로 막대(`sbar`) |
| **0 이 아닌 축** | 막대에서 축을 자르면 차이가 부풀어 보인다 | 막대는 항상 0에서. 꺾은선만 `"zero": false` 허용 |
| **모든 점에 라벨** | 다 강조하면 아무것도 강조가 아니다 | 처음 · 끝 · 꺾이는 곳만 |
| **색 여섯 가지** | 범례를 봐야 읽히는 그림은 이미 실패다 | 강조 하나만 색, 나머지는 `mute` |

**색은 부호가 아니라 좋고 나쁨이 정한다.** 마감일이 4일 줄어든 것은 음수지만 좋은 일이다.
워터폴에서 `good` / `bad` 를 직접 적는 이유가 이것이다. 부호로 자동 판정하면 개선이 붉게 칠해진다.

## 3. 표

### 3.1 열두 줄로 끝난다

1. **글자는 왼쪽, 숫자는 오른쪽.** 자릿수가 세로로 맞아야 눈이 훑는다(`class="num"`)
2. **머리행 정렬은 아래 칸을 따라간다.** 숫자 열의 머리도 오른쪽
3. **단위는 머리행에 한 번만.** `월 비용 (만원)`. 칸마다 "만원"을 붙이지 않는다
4. **소수점은 결정에 필요한 만큼만.** 임원 자료에 소수 둘째 자리를 끌고 가지 않는다
5. **합계는 맨 아래.** `tr.total` 이 위에 굵은 선을 긋는다
6. **행은 아홉을 넘기지 않는다.** 넘으면 묶거나 장을 나눈다
7. **열은 다섯을 넘기지 않는다.** 슬라이드 폭 1088px 기준
8. **열 폭을 `colgroup` 으로 고정한다.** 안 그러면 내용에 따라 폭이 흔들린다
9. **강조는 한 종류만.** `hi`(잘된 곳) 와 `warn`(나빠진 곳) 을 한 표에 둘 다 쓰면 둘 다 안 보인다
10. **빈 칸을 비워 두지 않는다.** 해당 없음이면 그렇게 적는다(`class="off"`)
11. **정도는 다섯 칸으로.** 일곱 칸이면 채우는 사람도 근거를 못 댄다(`hb`)
12. **표 아래 한 줄로 출처와 기간.** `class="cap"`

### 3.2 세 가지 꼴

| 꼴 | 언제 | 갤러리 |
|---|---|---|
| **비교표** | 항목마다 값이 두셋 붙는다. 합계가 뜻이 있다 | 03 |
| **평가 매트릭스** | 대안 두셋을 같은 축으로 잰다. 값이 정도다 | 04 |
| **강조표** | 숫자가 이미 있고 한 칸만 말하고 싶다 | 05 |

### 3.3 마크업

```html
<div class="tbl" data-anim style="--d:3">
  <table>
    <colgroup><col style="width:30%"><col style="width:22%">
              <col style="width:24%"><col style="width:24%"></colgroup>
    <thead><tr><th>업무</th><th>담당</th>
      <th class="num">월 처리 건수</th><th class="num">월 비용 (만원)</th></tr></thead>
    <tbody>
      <tr><td><b>기장 · 전표</b></td><td>담당 회계사</td>
          <td class="num">1,240</td><td class="num">180</td></tr>
      <tr class="total"><td>합계</td><td class="off">4개 업무</td>
          <td class="num">1,282</td><td class="num">450</td></tr>
    </tbody>
  </table>
  <div class="cap">예시 데이터 · 12개월 평균</div>
</div>
```

강조 칸은 `<td class="num hi">` 또는 `<td class="num warn">`.
정도는 `<td><span class="hb">●●●●○</span></td>`, 낮은 값은 `<span class="hb off">`.

## 4. 그래프

### 4.1 좌표를 손으로 쓰지 않는다

`scripts/mkchart.py` 가 숫자에서 조각을 뽑는다. 백분율과 SVG 좌표를 사람이 계산하면 틀리고,
틀려도 그림은 멀쩡해 보인다.

```
python scripts/mkchart.py spec.json -o frag.html
```

`spec.json` 은 하나든 배열이든 된다. 색은 토큰 이름으로만 준다(`a1` `a2` `a3` `risk` `rule` `line`).

| type | 무엇 | 핵심 옵션 |
|---|---|---|
| `bars` | 가로 막대 | `rows` `hi`(강조 행 번호) `unit` `labelw` |
| `sbar` | 100% 누적 가로 막대 | `names` `rows[].parts` |
| `cols` | 세로 막대 | `x` `v` `hi` `unit` |
| `stack` | 누적 세로 막대 | `x` `series[].v` |
| `wf` | 워터폴 | `items` = `[라벨, 값, tot\|good\|bad]` |
| `line` | 꺾은선 | `series[].mute` 로 비교 계열을 눕힌다. `zero:false` 로 축 해제 |
| `dot` | 점 | `points` = `[x, y, 라벨, 강조여부]` |
| `ccc` | 현금 회전일 | `dio` `dso` `dpo` |
| `range` | 축구장 (값 범위) | `rows[].lo/hi` `ref` |
| `bubble` | 두 축 + 크기 | `points[].x/y/r/hi` `xmid` `ymid` |
| `combo` | 막대 + 선 | `bars` `line` |
| `mekko` | 가변 폭 누적 | `cols[].w/parts` |
| `heat` | 민감도 표 | `rows` `cols` `v` `base` |

**재무제표를 분석하는 자리라면 `finance-views.md` 를 먼저 본다.** 뒤쪽 여섯은 거기서 쓰라고 만든 것이고,
뷰마다 무엇을 입력하고 어디서 틀리는지가 적혀 있다.

뽑은 조각은 슬라이드 본문에 그대로 넣는다.

```html
<div data-anim style="--d:3; display:flex; flex:1; min-height:0">
  <!-- mkchart 출력 -->
</div>
```

### 4.2 보고 따라 하고 싶은 그림이 되는 여섯 가지 (2026-09-01)

처음 판은 규칙은 맞았는데 그림이 구렸다. 무엇이 구렸는지 그대로 적어 둔다.

| 고친 것 | 무엇이 문제였나 |
|---|---|
| **회색 트랙 제거** | 막대 뒤에 회색 홈을 깔면 대시보드 진행바로 읽힌다. 축선 위에 막대만 세운다 |
| **가운데 정렬 폐기** | `justify-content:center` 라 위아래에 빈 자리가 남았다. `space-evenly` 로 자리를 다 먹는다 |
| **구성비는 단색 램프** | 파랑·인디고·앰버 세 색으로 쌓으면 총량보다 색이 먼저 읽힌다. `r2 → r3 → r4` 농담으로 |
| **값은 막대 끝에 직접** | 고정 폭 칸에 몰아 두면 막대와 값이 갈라진다. 끝에 붙이고 20px 로 키운다 |
| **주석은 콜아웃으로** | 회색 글씨로 아래에 흘리면 아무도 안 읽는다. 액센트 규칙선 + 옅은 면 |
| **세로 막대에 격자 둘** | 축 값이 없으면 중간 크기를 못 읽는다. 절반과 최대, 두 줄까지만 |

세부는 두 가지 더 있다. **워터폴에는 기둥 사이 연결선을 긋는다**(안 그으면 계단이 안 읽힌다).
**누적 칸 사이는 흰 선 1.5px 로 가른다**(색만으로 가르면 경계가 뭉갠다).

### 4.3 그래프 여덟 줄

1. **막대 축은 0에서.** 잘라야 할 만큼 차이가 작으면 그래프가 아니라 표로 간다
2. **가로 막대는 값 순으로 정렬.** 시간이 아니면 시간순으로 두지 않는다
3. **강조는 하나.** `hi` 에 행 번호를 넣으면 나머지가 회색으로 눕는다
4. **격자는 셋까지.** 그보다 많으면 데이터보다 격자가 진해진다
5. **범례보다 직접 라벨.** 계열이 셋 이하면 선 끝에 이름을 붙인다
6. **반올림.** 1,240 이면 충분하다. 1,239.5 는 읽히지 않는다
7. **아래 한 줄로 무엇을 봐야 하는지 적는다**(`cnote`). 그 아래 한 줄로 출처(`csrc`)
8. **점이 스무 개 미만이면 산점도 대신 표.** 다섯 점짜리 상관은 상관이 아니다

## 5. 도표와 단계

### 5.1 부호는 둘까지

한 그림이 질 수 있는 부호는 **위치 · 색 · 화살표 · 크기** 중 **둘**이다.
셋째가 들어오는 순간 그림 아래에 범례가 붙고, **범례가 붙었다는 것은 이미 진 것이다.**

실제로 물린 도표 하나를 놓고 보면 이렇다.

| 그 도표가 진 것 | 부호 |
|---|---|
| 업무 순서 | 화살표 |
| 입력이 일어나는 화면인가 | 테두리 색 |
| 어느 화면 밑에 붙는가 | 아래 매달린 상자 |
| 읽기 전용 참고 화면 | 회색 띠 |

넷을 한 장에 넣으니 아래에 설명 줄이 세 줄 붙었고, 매달린 상자 개수가 화면마다 달라서 아래가 들쭉날쭉해졌다.

**고치는 법은 장을 가르는 것이다.**

- 첫 장은 **순서만**. 상자 여섯 개를 한 줄로 세우고 화살표만 남긴다
- 둘째 장은 **표로**. 화면 이름 · 주인 · 읽기/쓰기를 열로 세운다
- 매달린 상자는 표의 행이 된다. 개수가 달라도 표는 안 흔들린다

### 5.2 판정 기준 셋

- 그림 아래 설명 줄이 **두 줄을 넘으면** 장을 나눈다
- 상자 안 글자가 **열 자를 넘으면** 표로 옮긴다
- 단계가 **다섯을 넘으면** 둘을 묶거나 장을 나눈다(`map` 은 여섯 칸에서 글자가 깨진다)

### 5.3 어느 컴포넌트로 가나

| 관계 | 컴포넌트 |
|---|---|
| 순서가 있는 3단계 | `flow` (role 셋 + banner) |
| 순서가 있는 4~5단계 | `map` (step + rail) |
| 순서 없는 병렬 3~4개 | `cards` |
| 둘의 대비 | `duo` |
| 항목마다 속성이 여럿 | **도표가 아니라 표** |

마지막 줄이 실무에서 제일 자주 어긋난다. 항목에 속성이 셋 이상 붙으면 그것은 도표로 그릴 것이 아니라 표다.
